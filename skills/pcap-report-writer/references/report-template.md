# Report Template

Use this when the user asks for a customer-facing or incident-style
write-up from packet evidence.

```markdown
# Packet Capture Analysis

## Summary

One paragraph. Say what the capture proves and avoid unsupported cause
claims.

## Evidence

| Evidence | Why it matters |
| --- | --- |
| Frame/UID/time | Interpretation |

## Conclusion

Use "consistent with" unless causality is directly visible.

## Limits

State missing vantage points, encryption, analyzer errors, truncation,
or absent logs.

## Next Steps

One to three concrete next actions.
```
